# Contributing to CAB

Thank you for your interest in improving the Christian AI Benchmark!

## Ways to Contribute

### 1. Question Review & Improvement
- Flag theological errors or biases
- Suggest clearer wording
- Identify missing topics

### 2. Translation
- Help translate questions to other languages
- Ensure theological terms translate accurately

### 3. Technical Improvements
- Improve evaluation scripts
- Add support for new model APIs
- Enhance documentation

### 4. Validation Studies
- Run the benchmark on models
- Compare results across runs
- Identify scoring inconsistencies

## How to Submit

1. **Fork** the repository
2. **Create a branch** (`git checkout -b improve-pastoral-questions`)
3. **Make changes** and commit
4. **Submit a Pull Request**

## Guidelines

- Maintain denominational balance (don't favor one tradition)
- Keep questions theologically defensible
- Test code changes before submitting
- Be respectful in discussions
